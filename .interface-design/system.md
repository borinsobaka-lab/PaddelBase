# Дизайн-система PaddelBase

Записано, чтобы следующий экран не пришлось изобретать заново. Всё ниже уже
стоит в коде — файлы указаны. Если решение нужно изменить, меняйте его здесь и
в токенах, а не локально в компоненте: два способа сделать одно и то же
расходятся быстрее, чем кажется.

## Кто по ту сторону экрана

Игрок в падел в Грузии, с телефоном в руке, чаще всего на ходу или между
делами. Открывает приложение ради одного из трёх вопросов:

1. Куда я записан?
2. Куда ещё можно записаться?
3. Что от меня сейчас требуется?

Экран, который не отвечает ни на один из них за один взгляд, сделан неверно.
Ширина проектирования — **390 px**; всё проверяется на ней.

## Мир и палитра

Палитра взята с корта, а не из абстрактной «светлой темы»:

- **Нейтралы** — стекло, увиденное с торца. Один холодный сине-зелёный тон
  (≈200°), меняется только светлота. Поэтому холст, поверхность и утопленное
  поле — родственники, а не три разных серых.
- **Акцент** — зелень корта, `#0a7a42`. Углублена до 5.4 : 1 с белым текстом.
- **Мяч** — `#d7e84a`. Единственная насыщенная точка на настоящем корте и
  единственный насыщенный цвет здесь. Значит ровно одно: **сейчас твой ход**.
  Больше нигде.

Токены — `apps/web/src/app/globals.css`. Хардкод цвета в компоненте считается
ошибкой.

## Сигнатура: состав как миниатюрный корт

`components/CourtLineup.tsx`. Падел всегда 2 × 2 на корте, разделённом сеткой.
Ряд кружков с инициалами этого не показывает — по нему не видно ни пар, ни с
какой стороны свободно место. Корт показывает и то и другое сразу.

Свободные места — пунктирные ячейки. Пустота здесь содержательна: это
приглашение, а не отсутствие данных.

Второй узнаваемый элемент — **дуга надёжности** вокруг уровня
(`components/LevelDial.tsx`). Она отвечает на вопрос «насколько этой цифре
можно верить»; без неё уровень новичка и ветерана выглядят одинаково весомо.

## Глубина: одна стратегия

Кольцо + мягкая тень (`shadow-raise` / `shadow-lift` / `shadow-float`).

- **Карточка** стоит на тени, без рамки.
- **Граница** остаётся там, где она разделяет: поля ввода, волосяные линии в
  списках, пунктир свободного места.
- **Поле ввода утоплено** (`bg-sunken`): более тёмная заливка сама говорит
  «сюда вводят», и тяжёлая рамка для этого не нужна.
- **Переключатель** — утопленная дорожка, выбранный вариант приподнят. Выбор
  читается по высоте, а не по цвету.

Смешивать нельзя: как только рядом окажутся карточка с рамкой и карточка с
тенью, обе начнут выглядеть случайными.

## Иерархия

Четыре уровня текста: `text` → `text-secondary` → `muted` → `faint`. Если
использованы только два, иерархия слишком плоская.

Работают три рычага вместе — размер, насыщенность, цвет. Внутри карточки
матча:

| Что | Как |
| --- | --- |
| Время | 16–19 px, semibold, `tabular` — по нему ищут матч в списке |
| День | тот же кегль, normal, `text-secondary` |
| Корт и длительность | 14 px, `muted` |
| Бейджи | 11 px, `label` |

**Один фокус на экран.** На главной это секция «Требует вас»; если её нет,
секции нет вовсе — пустой блок «ничего не требуется» только разбавлял бы
важное.

Цифры (уровень, счёт, очки) всегда `tabular`: значение не должно дёргаться
при изменении, а соседние строки должны выравниваться.

## Плотность и ритм

- Базовая единица 4 px.
- Карточка ленты — `p-3.5`, карточка фокуса — `p-4`.
- Между секциями — `gap-7` на главной, `gap-5` на детальных экранах.
- Внутри секции — `gap-3`.

Ленты для просмотра идут **вбок** (`.rail`, со скролл-снапом и вылетом за
край), свои матчи — **вниз**: чужие заявки листают, свои читают целиком.

## Цели нажатия

Минимум 44 px, без исключений. Текстовая ссылка в 20 px — самая частая причина
промахов; в таких местах стоит `MoreLink` или отрицательные поля с
`min-h-11`.

## Состояния

- **Пустое состояние зовёт к действию, а не извиняется.** Два варианта:
  `card` — для главного пустого состояния экрана (рамка, подсказка, кнопка);
  `quiet` — одна строка для второстепенных лент. Три одинаковые пунктирные
  рамки подряд весят одинаково, и игрок не понимает, с чего начать.
- **Ошибка говорит, что произошло и что делать** (`ErrorNote`).
- **Длинная форма** держит кнопку в `StickyBar`; пока форма не заполнена,
  кнопка тихая — яркая зелёная кнопка, которая ничего не делает, только
  провоцирует по ней жать.
- **Скелет загрузки** повторяет реальную раскладку, а не показывает спиннер.

## Движение

Только `transform` и `opacity`, только `--ease-out`, 140 мс. Нажатие —
`scale(0.975)`; ниже уже читается как сбой. Всё выключается при
`prefers-reduced-motion`.

## Что где лежит

| Слой | Файл |
| --- | --- |
| Токены, базовые утилиты | `apps/web/src/app/globals.css` |
| Примитивы (Card, Button, поля, Segmented, StickyBar, BackLink…) | `apps/web/src/components/ui.tsx` |
| Сигнатурные элементы | `CourtLineup.tsx`, `LevelDial.tsx`, `LevelStrip.tsx` |
| Карточки сущностей | `MatchCard.tsx`, `TournamentCard.tsx`, `PostCard.tsx` |
| Каркас | `AppShell.tsx`, `BottomNav.tsx`, `CreateButton.tsx` |

`AppShell` владеет нижним отступом: плавающая кнопка стоит над панелью, и если
про неё забыть, она накроет последнюю карточку списка.

## Отвергнутые умолчания

Записано, чтобы не вернуться к ним по инерции:

- Строка статистики в углу шапки → дуга надёжности.
- Три равновеликие секции на главной → одна фокусная плюс ленты.
- Ряд кружков с инициалами → корт.
- Плашка «рейтинг» на каждой карточке → помечается исключение «без рейтинга».
- Семь развёрнутых раундов подряд → раскрыт только текущий.
- Нативный `file input` с браузерной подписью → обычная кнопка.
- Серый SaaS-нейтрал → стеклянные нейтралы и жёлтый мяча.
